# Contributing

1. Open an issue for material design changes to the Answer Contract schema or Answer Share weights.
2. Keep the product-analytics pilot brand fictional (`Northline Analytics`) unless intentionally expanding verticals.
3. Do not commit API keys. Live captures belong under `data/live/` as JSON only.
4. Run `npm run typecheck` before opening a PR.

See `docs/` for architecture, pilot protocol, and API reference.
