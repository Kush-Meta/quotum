# Quotum — Answer Contracts

Publish intent-bound **Answer Contracts** for generative engines. Measure **Answer Share**. Run a causal pilot.

The product lives in [`quotum/`](./quotum/).

```bash
cd quotum && npm install && npm run dev
```
